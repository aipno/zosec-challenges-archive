### 内容
实现 solve(case)，返回矩形的 [面积, 周长]。

case 形如 {"width": 3, "height": 4}，宽和高都是非负整数。

示例：
3 x 4 -&gt; [12, 14]
5 x 2 -&gt; [10, 14]
0 x 5 -&gt; [0, 10]
